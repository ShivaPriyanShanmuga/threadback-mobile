# Actual iPhone test checklist

Open https://threadback-workspace.wirylapel.chatgpt.site in Safari. The first deployment is owner-private, so sign in with the owning ChatGPT account if prompted. Desktop task data will not automatically appear on the phone: storage is local to each browser. Use a new workspace or import an exported backup.

1. Create a short workspace and mark its first step done.
2. Tap **Use camera** and allow the camera for this app. Confirm a live rear-camera image appears.
3. Tap **Align workspace**, include a textured flat mat or printed page, and set a reference.
4. Place a marker for the active step. Move the phone a little; confirm the marker follows the reference plane.
5. Cover the camera or point away. The marker should disappear, then return only after a reliable match.
6. Open **Save checkpoint → Speak a note**. Say an unfinished detail and an explicit next action. Confirm the transcript and fields before saving.
7. If voice fails, note the error and whether Safari/Siri dictation is enabled; typed entry must still work.
8. Attach a fresh camera photo, save and pause.
9. Leave Safari, return, and reload. Verify the step, unfinished detail, next action, and photo evidence remain.
10. Open the resume packet, then complete the active step. The old unfinished detail must clear and the next step must advance.
11. Export a backup. Restore it and verify notes and photos.
12. Deny camera/microphone in a separate permission test; the app should explain the failure and retain typed/photo-import paths.

Record phone model, iOS version, browser, observed latency, and any tracking failure conditions. Do not infer phone success from the desktop test results.

After testing, open **Settings → Check this device**, run **Test saving a temporary record**, then **Copy report**. Share that report with the phone model/iOS version and any visible errors. It contains capability flags and observed outcomes, with no task names, notes, photos, or audio. Matching counts alone do not prove correct physical alignment; describe what you saw as well.
